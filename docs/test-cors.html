Le navigateur peut-il appeler l'API Sorare ?

Ouvre ce fichier dans ton navigateur (double-clic), puis lance « Tout tester ». Aucune clé n'est envoyée : la requête demande seulement { __typename }, que l'API sert à tout le monde. Pour voir le détail, ouvre aussi la console (F12, onglet Console et onglet Réseau).

Origine de cette page :

1. Appel normal de l'API Sorare (comme le ferait l'appli)

POST JSON vers https://api.sorare.com/graphql. Attendu : bloqué par le navigateur (« Failed to fetch » / « Load failed »), car Sorare n'autorise que l'origine https://sorare.com.


  


  

    
2. Même appel en mode « no-cors »

    
Le navigateur envoie la requête mais cache la réponse à la page : statut 0, contenu illisible. Preuve que Sorare répond, mais que la page n'a pas le droit de lire.

    

  


  

    
3. Témoin : ESPN, qui autorise tous les sites

    
GET de la liste des blessés NBA. Attendu : lu sans problème (ESPN renvoie Access-Control-Allow-Origin: *).
